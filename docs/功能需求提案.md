# 字境 · 功能需求提案（备份）

> 版本日期：2026-08-20  
> 状态：声母韵母已核对；核对入口已关闭；练习为读音 → 笔画 → 例句三关；选字按新华字典音序 + 侧边 26 字母  
> 产品名：字境（识字）  
> 定位：给孩子用的汉字读音 + 笔画 + 例句练习小游戏  
> 标语：读准音 · 写好字  
> 拼音字表参考：BV1RrySBCEmt《汉语拼音跟我读一读》（蓝莓爱语文，仅作筛字）

本文档备份截至今日已确认/已实现的功能需求，以及明确未完成项，便于后续开发与 GitHub 同步对照。

---

## 1. 产品目标

1. 在浏览器中完成「选字 → 听读音 → 写笔画 → 读例句 → 通关」闭环。
2. 读音示范以**课堂可用**的声母 / 韵母 / 整字为主，避免浏览器 TTS 把拼音读成英文或读错调。
3. 笔画练习用标准笔顺引导，完成时给点赞反馈。
4. 例句帮助把字放进短句里听、跟读。
5. 进度本地保存，无需登录。

## 3. 用户流程

```
首页
  → 选字（新华字典音序 + 侧边 A–Z + 通关标记）
    → 练习页（同一屏串联三关）
         ① 读音（听一听：声母 → 韵母 → 拼读整字）
         ② 笔画（听完后解锁描红；写对出点赞弹框）
         ③ 例句（描红完成后解锁；小喇叭播放）
    → 关卡完成
         → 下一字 / 返回选字
```

- **无独立进度页**：进度体现在选字网格的「已通关」与本地存储。
- 练习页为**同一屏三关**：先读音，再笔画，再例句。

## 4. 功能需求清单

### 4.1 字库与分组（已实现）

- 可练字库 **300** 字（原始条目含少量扩展韵母字，按视频字表过滤后保留 300）。
- 选字页签改为右侧 **A–Z** 26 个字母（《新华字典》音序），不再用「全部 / 自然 / 人物 / 生活 / 动物 / 学习」顶部分类。
- 排序：拼音字母 → 阴平/阳平/上声/去声 → 笔画少到多。
- 默认显示音序第一个有字的字母（A）；点右侧字母后，主区域**只显示该字母下的字**。无字字母灰显不可点。
- 字库内部仍保留主题字段（自然/人物等），仅供数据整理，界面不展示。
- 明确**不收录**轻声字作为主练目标：的、了、着、过、吗、呢、么 等。
- **只保留**声母+韵母落在 BV1RrySBCEmt 屏幕字表内的字：
  - 23 声母：`b p m f d t n l g k h j q x zh ch sh r z c s y w`
  - 24 韵母：`a o e i u ü / ai ei ui ao ou iu ie üe / er / an en in un ün / ang eng ing ong`
  - 不收录需 `ian/uo/ia/ua/iao/uan/iang/uang/iong` 等扩展韵母的字（如 千、小、家、火、鸟 等）。
- 界面**不展示**书籍来源或字库参考提示。

### 4.2 选字与进度（已实现）

- 选字网格展示汉字；已通关有视觉标记。
- 网格只展示当前字母下的汉字。
- 进度键：`localStorage` → `zijijing-progress-v2`（已完成字符 id 列表）。
- 通关条件：听完读音（点「听完了，去写字」）+ 描红完成 + 进入例句关并点「完成」。

### 4.3 读音练习（已实现）

#### 界面与步骤

- 音节拆分展示：`声母 + 韵母 = 拼读`（可点击切换当前步骤）。
- 「听一听」组合示范顺序：整字 → 停约 2 秒 → 声母 → 韵母 → 整字。
- 主操作：
  - **听一听**：播组合示范
  - **听完了，去写字**：解锁笔画（不强制必须先听完）
- **已去掉「我来读」**：不再做麦克风识别打分（设备差异大、声母韵母单独识别不稳定）。
- 发音指导：随当前步骤切换，展示口型与发音提示。
- **不口播**「声母 / 韵母 / 整字」等步骤名。

#### 示范音来源（当前 · 2026-08-19，已核对）

| 类型 | 策略 | 语速 |
|------|------|------|
| 声母 | 预录 `audio/initial-*.m4a` ← **主持人小史** BV1nUUhYHESM（按用户标定时间切片；y/w 未标定，仍用 TTS） | 约 0.65 倍速播放 |
| 韵母 | 预录 `audio/final-*.m4a` ← BV1Xm4y1R7c3《24个韵母正确发音及发音口型》 | **原速** |
| 整字 | 系统 TTS | 慢速跟读 |
| 回退 | 预录失败时用课堂汉字 / 带调拼音 TTS | 慢速 |

**字表范围参考：** BV1RrySBCEmt《汉语拼音跟我读一读》（筛字用，非当前切片声源）。

**说明：** 声母与韵母来自两位不同示范者；整字仍为系统音。用户已完成声母韵母核对，按此版发音使用；首页核对入口已关闭。

### 4.4 笔画练习（已实现）

- Hanzi Writer 笔顺测验。
- 支持：轮廓、绿色虚线引导、撤销、清空、演示。
- 读音关未点「去写字」前笔画区锁定。
- 正确描完全部笔画后弹出 **Q 版大拇指点赞弹框**（无分数、无文字）；点空白处或约 2 秒后关闭。
- 写完点「写完了，读例句」进入第三关。演示笔顺不弹点赞，只提示可重写或继续。

### 4.5 例句练习（已实现）

- 每字 1–2 句儿童向短句（`js/examples.js`），句中当前字标红。
- 每句旁有**小喇叭**，点击用系统 TTS 朗读该句。
- 例句语速约 **0.5 倍**（便于跟读）。
- 描红完成前第三关锁定。

### 4.6 环境适配（已实现）

- 微信内提示：播报可能无声，建议在系统浏览器打开；也可先去写字。
- 无 TTS 时提示可直接进入写字。

## 5. 交互与体验约定（已确认）

| 主题 | 约定 |
|------|------|
| 读音 UI | 音节拆分 + 发音指导；无麦克风跟读 |
| 按钮文案 | 儿童向：「听一听」「听完了，去写字」「写完了，读例句」 |
| 示范内容 | 不播报「声母」「韵母」「整字」口头标签 |
| 语速 | 声母预录略慢；韵母原速；整字 TTS 慢；例句约 0.5 倍 |
| 描红反馈 | 仅点赞弹框动画，不打分、不配文字 |
| 选字 | 右侧 A–Z 双列大按钮；选中为鲜绿；点字母只显示该组；默认 A |
| 看图选字 | 已废弃；当前为直接选字 |

## 6. backlog

- 整字若也要预录，需另备字表跟读素材。
- 部分字缺少 `strokeNames`（不影响笔顺）。
- 声母/韵母目前非同一人声，若要完全统一音色需同人素材。
- 例句目前为系统 TTS；若要课堂人声需另录。

## 10. 验收标准（当前可测）

1. 强刷 `http://127.0.0.1:8767/`（`?v=20260820f`）。
2. 首页只有「开始识字」，无「核对声母韵母」入口；无书籍/字库参考提示；无「我来读」。
3. 点「开始识字」：右侧 A–Z；默认只显示 A 组字；点 B 则只显示 B 组，不再列出其他字母条。
4. 选字数量 **300**；不含轻声助词；不含 ian/uo 等扩展韵母字。
5. 「听一听」：声母小史预录（略慢）、韵母 BV1Xm4y1R7c3 原速、整字系统慢速 TTS；顺序为整字 → 停 2 秒 → 声母 → 韵母 → 整字。
6. 描红写对弹出大拇指点赞弹框；再进入例句关，小喇叭约 0.5 倍速朗读；「完成」后通关。
