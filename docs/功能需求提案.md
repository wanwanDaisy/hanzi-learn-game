# 字境 · 功能需求提案（备份）

> 版本日期：2026-08-19  
> 状态：声母韵母已按此版发音核对完成；核对入口已关闭  
> 产品名：字境（识字）  
> 定位：给孩子用的汉字读音 + 笔画练习小游戏  
> 标语：读准音 · 写好字  
> 拼音字表参考：BV1RrySBCEmt《汉语拼音跟我读一读》（蓝莓爱语文，仅作筛字）

本文档备份截至今日已确认/已实现的功能需求，以及明确未完成项，便于后续开发与 GitHub 同步对照。

---

## 1. 产品目标

1. 在浏览器中完成「选字 → 读准 → 写对 → 通关」闭环。
2. 读音校准以**课堂可用**的声母 / 韵母 / 整字示范为主，避免浏览器 TTS 把拼音读成英文或读错调。
3. 笔画练习用标准笔顺引导，降低挫败感。
4. 进度本地保存，无需登录。

---

|----|------|

---

## 3. 用户流程

```
首页
  → 选字（分组 + 通关标记）
    → 练习页
         ① 读音（声母 → 韵母 → 拼读整字）
         ② 笔画（读音通过或跳过后方可写）
    → 关卡完成
         → 下一字 / 返回选字
```

- **无独立进度页**：进度体现在选字网格的「已通关」与本地存储。
- 练习页为**同一屏串联**：先读音后笔画，不是两个独立关卡页。

## 4. 功能需求清单

### 4.1 字库与分组（已实现）

- 可练字库 **300** 字（原始条目含少量扩展韵母字，按视频字表过滤后保留 300）。
- 分组：全部 / 自然 / 人物 / 生活 / 动物 / 学习。
- 明确**不收录**轻声字作为主练目标：的、了、着、过、吗、呢、么 等。
- **只保留**声母+韵母落在 BV1RrySBCEmt 屏幕字表内的字：
  - 23 声母：`b p m f d t n l g k h j q x zh ch sh r z c s y w`
  - 24 韵母：`a o e i u ü / ai ei ui ao ou iu ie üe / er / an en in un ün / ang eng ing ong`
  - 不收录需 `ian/uo/ia/ua/iao/uan/iang/uang/iong` 等扩展韵母的字（如 千、小、家、火、鸟 等）。
- 界面**不展示**书籍来源或字库参考提示。

### 4.2 选字与进度（已实现）

- 选字网格展示汉字；已通关有视觉标记。
- 进度键：`localStorage` → `zijijing-progress-v2`（已完成字符 id 列表）。
- 通关条件：读音流程完成（通过或跳过）+ 笔画练习完成。

### 4.3 读音练习（已实现主体）

#### 界面与步骤

- 音节拆分展示：`声母 + 韵母 = 拼读`（可点击切换当前步骤）。
- 步骤顺序：
  1. **声母**（零声母字可跳过声母步）
  2. **韵母**
  3. **整字 / 拼读**
- 主操作：
  - **听一听**：播当前步示范音
  - **我来读**：麦克风跟读打分（支持环境下降级）
  - 可跳过读音以解锁笔画（允许「先写后听」）
- 发音指导：随当前步骤切换，展示声母 / 韵母 / 拼读的口型与发音提示。

#### 组合示范（听组合）

固定顺序：

1. 先播**整字**
2. 停顿约 **2 秒**
3. 再播 **声母 → 韵母 → 整字**
4. 步骤之间约 **0.75 秒**间隔  
5. **不口播**「声母 / 韵母 / 整字」等步骤名

#### 示范音来源（当前 · 2026-08-19，已核对）

| 类型 | 策略 |
|------|------|
| 声母 | 预录 `audio/initial-*.m4a` ← **主持人小史** BV1nUUhYHESM（按用户标定时间切片；y/w 未标定，仍用 TTS） |
| 韵母 | 预录 `audio/final-*.m4a` ← BV1Xm4y1R7c3《24个韵母正确发音及发音口型》 |
| 整字 | 系统 TTS |
| 回退 | 预录失败时用课堂汉字 / 带调拼音 TTS |

**字表范围参考：** BV1RrySBCEmt《汉语拼音跟我读一读》（筛字用，非当前切片声源）。

**说明：** 声母与韵母来自两位不同示范者；整字仍为系统音。用户已完成声母韵母核对，按此版发音使用；首页核对入口已关闭。

#### 识别与打分（已实现）

- Web Speech API，`zh-CN`，多候选比对。
- 分项模式：initial / final / full。
- 通过阈值：声母/韵母约 **0.55**，整字约 **0.62**。
- 三项通过（或跳过策略满足）后解锁笔画。

### 4.4 笔画练习（已实现）

- Hanzi Writer 笔顺测验。
- 支持：轮廓、绿色虚线引导、撤销、清空、演示。
- 读音未完成前笔画区锁定；跳过读音也可解锁。

### 4.5 环境适配（已实现）

- 微信内提示浏览器限制。
- 无识别能力时：隐藏或降级麦克风校准，保留听示范。

## 5. 交互与体验约定（已确认）

| 主题 | 约定 |
|------|------|
| 读音 UI | 去掉早期「三行步骤条」等冗余；保留音节拆分 + 发音指导 |
| 按钮文案 | 儿童向：「听一听」「我来读」 |
| 示范内容 | 不播报「声母」「韵母」「整字」口头标签 |
| 语速 | 示范明显慢于日常 TTS（便于跟读） |
| 看图选字 | 早期方案已废弃；当前为直接选字 + 读音/笔画 |

## 6. backlog

- 整字若也要预录，需另备字表跟读素材。
- 部分字缺少 `strokeNames`（不影响笔顺）。
- 声母/韵母目前非同一人声，若要完全统一音色需同人素材。

## 10. 验收标准（当前可测）

1. 强刷 `http://127.0.0.1:8767/`（`?v=20260819o`）。
2. 首页只有「开始识字」，无「核对声母韵母」入口；无书籍/字库参考提示。
3. 选字数量 **300**；不含轻声助词；不含 ian/uo 等扩展韵母字。
4. 「听一听」声母播小史预录、韵母播 BV1Xm4y1R7c3 预录、整字为系统 TTS。
5. 「听组合示范」顺序：整字 → 停 2 秒 → 声母 → 韵母 → 整字。
6. Chrome 下「我来读」可出分；笔画解锁与通关正常。
