# 字境 · 功能需求提案（备份）

> 版本日期：2026-10-15  
> 状态：声母韵母已核对；核对入口已关闭；练习为读音 → 笔画 → 例句三关（拼音描红暂隐）；选字按新华字典音序 + 侧边 26 字母  
> 产品名：字境（认字与数数）  
> 定位：给孩子用的汉字读音 + 笔画 + 例句练习小游戏  
> 标语：读准音 · 写好字  
> 拼音字表参考：BV1RrySBCEmt《汉语拼音跟我读一读》（蓝莓爱语文，仅作筛字）

本文档备份截至今日已确认/已实现的功能需求，以及明确未完成项，便于后续开发与 GitHub 同步对照。

---

## 1. 产品目标

1. 在浏览器中完成「选字 → 听读音 → 写笔画 → 读例句 → 通关」闭环。
2. 读音示范以**课堂可用**的声母 / 韵母 / 整字为主，避免浏览器 TTS 把拼音读成英文或读错调。
3. 读音关用课堂**四线三格**展示声母、韵母、拼读（书写描红待教材对照后再开）。
4. 笔画练习用标准笔顺引导，完成时给点赞反馈。
5. 例句帮助把字放进短句里听、跟读。
6. 进度本地保存，无需登录。

## 3. 用户流程

```
首页
  → 选字（新华字典音序 + 侧边 A–Z + 通关标记）
    → 练习页（同一屏串联三关）
         ① 读音（听一听；声母 / 韵母 / 拼读以四线三格展示）
         ② 笔画（听完读音后解锁描红；写对出点赞弹框）
         ③ 例句（描红完成后解锁；小喇叭播放）
    → 关卡完成
         → 下一字 / 返回选字
```

- **无独立进度页**：进度体现在选字网格的「已通关」与本地存储。
- 练习页为**同一屏三关**：先读音，再笔画，再例句。拼音描红关暂隐，待有教材字模后再开。

## 4. 功能需求清单

### 4.1 字库与分组（已实现）

- 可练字库 **1000** 字：保留原有 300 字及其 id，新增 700 字，按原有韵母范围筛选。
- 选字页签改为右侧 **A–Z** 26 个字母（《新华字典》音序），不再用「全部 / 自然 / 人物 / 生活 / 动物 / 学习」顶部分类。
- 排序：拼音字母 → 阴平/阳平/上声/去声 → 笔画少到多。
- 默认显示音序第一个有字的字母（A）；点右侧字母后，主区域**只显示该字母下的字**。无字字母灰显不可点。
- 字库内部仍保留主题字段（自然/人物等），仅供数据整理，界面不展示。
- 明确**不收录**轻声字作为主练目标：的、了、着、过、吗、呢、么 等。
- **只保留**声母+韵母落在 BV1RrySBCEmt 屏幕字表内的字：
  - 23 声母：`b p m f d t n l g k h j q x zh ch sh r z c s y w`
  - 24 韵母：`a o e i u ü / ai ei ui ao ou iu ie üe / er / an en in un ün / ang eng ing ong`
  - 不收录需 `ian/uo/ia/ua/iao/uan/iang/uang/iong` 等扩展韵母的字（如 千、小、家、火、鸟 等）。
- 界面**不展示**书籍来源或字库参考提示。

### 4.2 选字与进度（已实现）

- 选字网格展示汉字；已通关有视觉标记。
- 网格只展示当前字母下的汉字。
- 进度键：`localStorage` → `zijijing-progress-v2`（已完成字符 id 列表）。
- 通关条件：听完读音（点「听完了，去写汉字」）+ 描红完成 + 进入例句关并点「完成」。

### 4.3 读音练习（已实现）

#### 界面与步骤

- 音节拆分展示：`声母 + 韵母 = 拼读`，三者都画在**四线三格**里（只看不描），拼音用**霞鹜文楷**。
- 「听一听」组合示范顺序：整字 → 停约 2 秒 → 声母 → 韵母 → 整字。
- 主操作：
  - **听一听**：播组合示范
  - **听完了，去写汉字**：解锁笔画描红（不强制必须先听完）
- **已去掉「我来读」**：不再做麦克风识别打分（设备差异大、声母韵母单独识别不稳定）。
- 发音指导：随当前步骤切换，展示口型与发音提示。
- **不口播**「声母 / 韵母 / 整字」等步骤名。

#### 示范音来源（当前 · 2026-08-19，已核对）

| 类型 | 策略 | 语速 |
|------|------|------|
| 声母 | 预录 `audio/initial-*.m4a` ← **主持人小史** BV1nUUhYHESM（按用户标定时间切片；y/w 未标定，仍用 TTS） | 约 0.65 倍速播放 |
| 韵母 | 预录 `audio/final-*.m4a` ← BV1Xm4y1R7c3《24个韵母正确发音及发音口型》 | **原速** |
| 整字 | 系统 TTS | 慢速跟读 |
| 回退 | 预录失败时用课堂汉字 / 带调拼音 TTS | 慢速 |

**字表范围参考：** BV1RrySBCEmt《汉语拼音跟我读一读》（筛字用，非当前切片声源）。

**说明：** 声母与韵母来自两位不同示范者；整字仍为系统音。用户已完成声母韵母核对，按此版发音使用；首页核对入口已关闭。

### 4.4 拼音书写（暂隐）

- 代码仍保留四线三格描红与笔顺演示，界面第二关已隐藏。
- 待有部编/人教一年级描红页对照后，再打开并校正字模。
- 当前四线三格规则用在读音关的声母 / 韵母 / 拼读展示。

### 4.5 笔画练习（已实现）

- Hanzi Writer 笔顺测验。
- 支持：轮廓、绿色虚线引导、撤销、清空、演示。
- 读音关未点「去写汉字」前笔画区锁定。
- 正确描完全部笔画后弹出 **Q 版大拇指点赞弹框**（无分数、无文字）；点空白处或约 2 秒后关闭。
- 写完点「写完了，读例句」进入第三关。演示笔顺不弹点赞，只提示可重写或继续。

### 4.6 例句练习（已实现）

- 每字 1–2 句儿童向短句（`js/examples.js`），句中当前字标红。
- 每句旁有**小喇叭**，点击用系统 TTS 朗读该句。
- 例句语速约 **0.5 倍**（便于跟读）。
- 描红完成前第三关锁定。

### 4.7 环境适配（已实现）

- 微信内提示：播报可能无声，建议在系统浏览器打开；也可先去写汉字。
- 无 TTS 时提示可直接进入写汉字。

## 5. 交互与体验约定（已确认）

| 主题 | 约定 |
|------|------|
| 读音 UI | 音节拆分 + 发音指导；无麦克风跟读 |
| 按钮文案 | 儿童向：「听一听」「听完了，去写汉字」「写完了，读例句」 |
| 示范内容 | 不播报「声母」「韵母」「整字」口头标签 |
| 语速 | 声母预录略慢；韵母原速；整字 TTS 慢；例句约 0.5 倍 |
| 拼音展示 | 读音关四线三格只看不描；书写关暂隐 |
| 描红反馈 | 仅点赞弹框动画，不打分、不配文字 |
| 选字 | 右侧 A–Z 双列大按钮；选中为鲜绿；点字母只显示该组；默认 A |
| 看图选字 | 已废弃；当前为直接选字 |

## 10. 验收标准（当前可测）

1. 强刷 `http://127.0.0.1:8767/`（`?v=20260824e`）。
2. 首页提供「认字游戏 / 开始识字」与「数数游戏 / 开始数数」两个入口，无「核对声母韵母」入口；无书籍/字库参考提示；无「我来读」。
3. 点「开始识字」：右侧 A–Z；默认只显示 A 组字；点 B 则只显示 B 组，不再列出其他字母条。
4. 选字数量 **1000**；不含轻声助词；不含 ian/uo 等扩展韵母字。
5. 「听一听」：声母小史预录（略慢）、韵母 BV1Xm4y1R7c3 原速、整字系统慢速 TTS；顺序为整字 → 停 2 秒 → 声母 → 韵母 → 整字。声母、韵母、拼读以四线三格展示。
6. 听完点「去写汉字」进入笔画关；无拼音描红关。
7. 描红写对弹出大拇指点赞弹框；再进入例句关，小喇叭约 0.5 倍速朗读；「完成」后通关。

## 12. 小学数学模块（2026-10-10）

- 统一首页提供「认字游戏」和「数数游戏」；数学页面和完成页均可返回首页切换游戏。
- 认字沿用读音 → 笔画 → 例句流程及原有进度；2026-10-13 已从 300 字扩充到 1000 字。
- 数数游戏提供 5 以内、10 以内范围，以及加法、减法、加减混合。
- 操作数与结果均为所选范围内的非负整数，包含 0；加法结果不超过上限，减法被减数不小于减数。
- 每轮随机 5 题，同轮题目不重复；四个不同候选答案，只有一个正确答案。
- 苹果展示数量：加法显示两组，减法给拿走的苹果加斜线；「帮我数一数」显示计数提示。
- 答错可重试，不扣分、不计时；答对后手动下一题，完成 5 题显示点赞完成页，可再来一轮。
- 切换范围或玩法开始新一轮；数学轮次不持久保存，不影响识字进度。
- 数学独立静态页面，无外部资源和语音依赖，支持手机、平板布局。
- 发布新增文件：`math.html`、`math.css`、`js/math.js`；同时更新 `index.html`、`styles.css`、本提案。`docs/math-preview.html` 保留为原型参考，不是正式入口。

### 视觉统一（2026-10-10）

认字模块的选字、读音、描红、例句与完成页参考数学模块：浅米绿背景、白色圆角卡片、绿色主按钮与浅绿辅助按钮，减少渐变和阴影。保留楷体汉字、四线三格、右侧 A–Z 导航和原有练习流程；手机单列练习，选字卡双列展示。首页两张插画入口保留独立样式。

## 14. 复习考核（2026-10-14）

- 入口位于认字游戏选字页介绍区右侧，采用绿色检查清单小图标搭配“复习考核”短标签；考核页左上角返回选字，保留原先的学习流程和进度。
- “已认识”暂按已通关字定义，从当前浏览器的 `zijijing-progress-v2` 中取有效字 id。每轮随机抽 5 个不同的字；不足 5 字取全部；没有记录时引导先学习。
- 每字先考读音，再考书写。认读时只显示楷体汉字、不展示拼音；孩子先读，点核对后显示带调拼音和词语，可听原有系统整字参考音，由家长确认是否正确。没有自动录音、语音识别或机器读音评分。
- 书写使用空白田字格默写，Hanzi Writer 检查目标字笔形及笔顺；初始无轮廓、无自动提示。主动看字模、出现错笔或重新写，均记录为需要巩固；独立无错完成才记为书写已掌握。该检测不等于完整的自由手写识别或书法评分。
- 字模失败可重试；跳过记为书写未检查，不计为掌握。异步加载期间退出或切换字，旧回调不得污染新题。
- 每轮结果分读音、书写展示；可重新抽题，或再练本轮需要巩固的字。最近 20 轮完成记录单独保存在 `zijijing-review-v1`，入口显示上轮概况及待巩固字；不删除原学习记录，中途退出不保存未完成一轮。
- 配色和大按钮延续现有绿色儿童风格，支持手机和平板，不计时。
- 新增文件：`review.html`、`review.css`、`js/review.js`、`js/review-core.js`；更新 `index.html`、`js/app.js` 和本提案。上线需一并上传上述文件。
