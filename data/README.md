# 字库扩充数据

2026-10-13：保留原有300字及其id，新增700字，总计1000个不重复汉字。保持原有24韵母筛选范围，不采用试听合成音。

- `expanded-lessons.txt`：本项目编写的700字词语和例句，每行的竖线左侧为“字:词语”，右侧为对应例句。
- `../js/characters-extra.js`：运行时新增字库，包含拼音、词语、例句和笔画数。新增id按Unicode码点命名，避免同音字冲突。
- 拼音和笔画数参考 [hanziDB.csv](https://github.com/ruddfawcett/hanziDB.csv) 的 data/hanziDB.json。按频率顺序选取满足既有韵母范围的字；不声称是教材指定1000字。许可证见 `hanziDB-LICENSE.txt`。
- 排除轻声“呀”，补入“奋”；“著”选zhù（著名），“甚”校正shèn（甚至），“迹”校正jì（足迹），“差”选chā（差别）。
- 多音字本轮只教授与例句一致的一种读音。固定整字音频仍未接入；系统朗读多音字可能需要后续人工核对。
